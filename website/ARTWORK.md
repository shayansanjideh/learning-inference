# Artwork color update

The homepage and lesson 1 illustrations were edited with the built-in image-generation tool to match the off-white theme. Assets: `dist/postcards/ink-landscape.png` and `dist/postcards/lesson-01-coast.png`.

Prompt used for each existing illustration:

> Edit only the paper/background color of this existing ink illustration. Replace all yellow/beige paper areas, including negative space between strokes, with near-white warm off-white #f7f5ef (RGB 247,245,239). Preserve the exact scene, composition, fine blue/orange/green ink strokes and details. No new objects, no change of style. Uniform off-white margins, no gradients or stains, no frame. Keep the existing artwork dimensions and all artwork.

The five images in `lessons/01-baseline/thread-images/` are fresh browser screenshots of the updated website. Chart data and labels come from the existing measured results.
